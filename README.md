🌏Arena Survival

A 3D survival game developed with Unity and C#.

About the Project

Arena Survival is a game development project focused on learning Unity, programming gameplay mechanics, and building a playable survival experience.

🔥Planned Features

1. Player movement

2. Enemy AI

3. Player health and damage system

4. Combat mechanics

5. Enemy spawning

6. Survival waves

7. Main menu and UI

🛰Technologies

Game Engine: Unity

Programming Language: C#

Version Control: Git and GitHub
